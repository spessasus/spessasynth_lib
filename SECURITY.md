# Security policy

## Supported versions

Only the latest release of spessasynth_lib is supported.
Please ensure that the problem still happens there before reporting it.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting instead, with the "Report a vulnerability" button in the Security tab of this repository.

Include the version, the steps or the file that trigger the problem, and what happens.
